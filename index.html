Мобильный терминал сбора данных
+ фискальный регистратор

Кроссплатформенное приложение на Supabase с реалтайм-синхронизацией остатков, CV-распознаванием товаров и цифровой «долговой тетрадью». Архитектура зафиксирована.

MODULE 01

Динамический каталог

Плиточная модель products ⇄ boutiques через JSON-конфиг, без изменения схемы данных.

MODULE 02

Компьютерное зрение

On-device детекция → классификация SKU → быстрое подтверждение количества.

MODULE 03

Взаиморасчеты

Статусы cash / debt / podryal, частичное погашение, append-only аудит.

Инварианты (не менять без новой ревизии)

  • Смартфон — ввод и расчет, не фискализация.
  • Внешний ККМ — фискализация и печать.
  • receipt_uuid — ключ идемпотентности на всех уровнях.
  • Общие таблицы операций/остатков/долгов для обоих режимов.
  • SHA-256-сверка обновлений — обязательна.
  • Закрытый Telegram-канал — транспорт; Supabase — авторитет.
  • Append-only для финансов; корректировки — компенсирующими записями.

Два режима работы

РЕЖИМ A

Автономная ККМ

Смартфон выполняет расчет и фискализацию через встроенный/облачный модуль.

  • SDK провайдера (облачная ККМ / программный ФН)
  • Зависимость от сети (если нет локального ФН)
  • Одна точка отказа — само устройство
  • Чек/QR — с экрана или по ссылке
РЕЖИМ B

Мобильный терминал → внешний ККМ

Смартфон — только ввод и распознавание. Фискализация — на внешнем ККМ.

  • BLE / USB / LAN, протоколы ESC/POS, АТОЛ, Штрих-М
  • Внешний ККМ офлайн-способен (ФН внутри)
  • Один терминал может обслуживать несколько ККМ
  • Выгрузка процесса — идемпотентно по receipt_uuid

Абстракция FiscalAdapter

interface FiscalAdapter {
  readonly mode: 'embedded' | 'external';
  registerSale(req: SaleRequest): Promise<FiscalResult>;
  registerRefund(req: RefundRequest): Promise<FiscalResult>;
  zReport(): Promise<ZReportResult>;
  healthCheck(): Promise<AdapterHealth>;
}

type SaleRequest = {
  receipt_uuid: string;          // идемпотентность
  items: { sku: string; qty: number; price: number; sum: number }[];
  payments: { type: 'cash' | 'debt' | 'podryal'; amount: number; counterparty_id?: string }[];
  total: number;
  device_id: string;
  kkm_id?: string;               // для external
};

type FiscalResult = {
  status: 'ok' | 'failed' | 'pending';
  fd?: string; fpd?: string; qr?: string;
  provider: string;              // имя SDK/ККМ
  raw?: unknown;
  error?: string;
};

Дистрибуция и целостность

git tag → CI (private runner): 1. build + sign APK (keystore из секретов) 2. upload APK → Supabase Storage (private bucket) 3. insert row → releases + manifest (источник истины) 4. publish → закрытый Telegram-канал (sendDocument) 5. (опц.) уведомление админ-чата Клиент: 1. GET /latest-release → manifest {version_code, sha256, apk_url} 2. сравнить version_code → если новее 3. скачать APK (из канала или по signed URL) 4. посчитать SHA-256 → сверить с manifest.sha256 5. установить только при совпадении

Транспорт

Закрытый Telegram-канал. Участники добавляются вручную. Бот — админ канала, публикует сборки.

Источник истины

Supabase: таблица releases + приватный bucket. Манифест авторитетен, сообщение в канале — лишь подсказка.

Контроль

SHA-256 из манифеста. При несовпадении — файл удаляется, установка блокируется, событие логируется в client_pings.

Клиентская сверка (обязательна)

Future<void> downloadAndInstall(ReleaseInfo m) async {
  final file = await _download(m.apkUrl);
  final actual = sha256.convert(await file.readAsBytes()).toString();
  if (actual != m.sha256) {
    await file.delete();
    throw IntegrityException('SHA-256 mismatch');
  }
  await installApk(file);  // FileProvider + ACTION_VIEW
}

  entity_id   uuid,
  action      text not null,          -- insert | compensate | status_change

0002 · Каталог и остатки

create table public.products (
  id uuid primary key default gen_random_uuid(),
  sku text not null unique,
  name text not null,
  price numeric(12,2) not null check (price >= 0),
  boutique_id uuid,
  cv_embedding vector(512),
  active boolean not null default true,
  created_at timestamptz not null default now()
);

create table public.stock_levels (
  product_id uuid not null references public.products(id) on delete cascade,
  location_id uuid not null,
  qty int not null default 0 check (qty >= 0),
  updated_at timestamptz not null default now(),
  primary key (product_id, location_id)
);
alter publication supabase_realtime add table public.stock_levels;

create or replace function public.decrement_stock(
  p_product uuid, p_location uuid, p_qty int
) returns void language plpgsql security definer as $$
begin
  update public.stock_levels
     set qty = qty - p_qty, updated_at = now()
   where product_id = p_product and location_id = p_location and qty >= p_qty;
  if not found then
    raise exception 'insufficient_stock' using errcode = 'P0001';
  end if;
end $$;

0003 · Контрагенты и долги

create table public.counterparties (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  status text not null check (status in ('cash','debt','podryal')),
  phone text,
  created_at timestamptz not null default now()
);

create table public.debts (
  id uuid primary key default gen_random_uuid(),
  counterparty_id uuid not null references public.counterparties(id),
  amount numeric(12,2) not null check (amount > 0),
  effective_date date not null default current_date,
  created_at timestamptz not null default now()
);

create table public.payments (
  id uuid primary key default gen_random_uuid(),
  debt_id uuid not null references public.debts(id),
  amount numeric(12,2) not null check (amount > 0),
  method text not null check (method in ('cash','transfer','offset')),
  effective_date date not null default current_date,
  created_at timestamptz not null default now()
);

create or replace view public.debt_balances as
select d.id as debt_id, d.counterparty_id, d.amount,
       coalesce(sum(p.amount),0) as paid,
       d.amount - coalesce(sum(p.amount),0) as balance
from public.debts d
left join public.payments p on p.debt_id = d.id
group by d.id, d.counterparty_id, d.amount;

0004 · Фискализация и транзакции

create table public.transactions (
  id uuid primary key,                 -- receipt_uuid
  device_id text not null,
  location_id uuid,
  counterparty_id uuid,
  items jsonb not null,
  total numeric(12,2) not null,
  payment_type text not null check (payment_type in ('cash','debt','podryal')),
  status text not null default 'pending'
    check (status in ('pending','fiscal_pending','fiscalized','failed','compensated')),
  created_at timestamptz not null default now()
);

create table public.fiscal_receipts (
  id uuid primary key default gen_random_uuid(),
  receipt_uuid uuid not null unique references public.transactions(id),
  provider text not null,
  kkm_id text,
  fd text, fpd text, qr text,
  sum numeric(12,2) not null,
  raw jsonb,
  status text not null default 'ok' check (status in ('ok','pending','failed')),
  created_at timestamptz not null default now()
);

create or replace function public.register_sale(
  p_receipt uuid, p_device text, p_items jsonb, p_total numeric,
  p_payment_type text, p_provider text, p_kkm_id text,
  p_fd text, p_fpd text, p_qr text, p_raw jsonb
) returns void language plpgsql security definer as $$
begin
  if exists(select 1 from public.transactions where id = p_receipt) then return; end if;

  insert into public.transactions(id, device_id, items, total, payment_type, status)
  values (p_receipt, p_device, p_items, p_total, p_payment_type, 'fiscalized');

  insert into public.fiscal_receipts(receipt_uuid, provider, kkm_id, fd, fpd, qr, sum, raw, status)
  values (p_receipt, p_provider, p_kkm_id, p_fd, p_fpd, p_qr, p_total, p_raw, 'ok');

  perform public.decrement_stock(
    (it->>'product_id')::uuid,
    (it->>'location_id')::uuid,
    (it->>'qty')::int
  ) from jsonb_arra

  method text not null check (method in ('cash','transfer','offset')),
  effective_date date not null default current_date,
  created_at timestamptz not null default now()
);

create or replace view public.debt_balances as
select d.id as debt_id, d.counterparty_id, d.amount,
       coalesce(sum(p.amount),0) as paid,
       d.amount - coalesce(sum(p.amount),0) as balance
from public.debts d
left join public.payments p on p.debt_id = d.id
group by d.id, d.counterparty_id, d.amount;

create or replace function public.register_sale(

  p_payment_type text, p_provider text, p_kkm_id text,
  p_fd text, p_fpd text, p_qr text, p_raw jsonb

begin
  if exists(select 1 from public.transactions where id = p_receipt) then return; end if;

  values (p_receipt, p_device, p_items, p_total, p_payment_type, 'fiscalized');

  perform public.decrement_stock(
    (it->>'product_id')::uuid,
    (it->>'location_id')::uuid,
    (it->>'qty')::int
  ) from jsonb_array_elements(p_items) it;

import { createClient } from "https://esm.sh/@supabase/supabase-js@2";

const admin = createClient(
  Deno.env.get("SUPABASE_URL")!,
  Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!,
  { auth: { persistSession: false } },
);

const CORS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "authorization, apikey, content-type",
};
const json = (b: unknown, s = 200) =>
  new Response(JSON.stringify(b), {
    status: s,
    headers: { "Content-Type": "application/json", ...CORS },
  });

Deno.serve(async (req) => {
  if (req.method === "OPTIONS") return new Response("ok", { headers: CORS });
  if (req.method !== "GET") return json({ error: "method_not_allowed" }, 405);

  const url = new URL(req.url);
  const platform = url.searchParams.get("platform") ?? "android";
  const channel  = url.searchParams.get("channel") ?? "stable";

  const { data: rel, error } = await admin
    .from("releases")
    .select("version_name, version_code, min_supported_code, apk_path, sha256, changelog, rollout_percent, published_at")
    .eq("platform", platform).eq("channel", channel).eq("revoked", false)
    .lte("published_at", new Date().toISOString())
    .order("version_code", { ascending: false }).limit(1).maybeSingle();

  if (error) return json({ error: "db_error" }, 500);
  if (!rel)   return json({ error: "no_release" }, 404);

  const { data: signed, error: sErr } = await admin.storage
    .from("releases").createSignedUrl(rel.apk_path, 60 * 60);
  if (sErr || !signed?.signedUrl) return json({ error: "sign_error" }, 500);

  return new Response(JSON.stringify({
    platform, channel,
    version_name: rel.version_name,
    version_code: rel.version_code,
    min_supported_code: rel.min_supported_code,
    sha256: rel.sha256,
    changelog: rel.changelog,
    rollout_percent: rel.rollout_percent,
    published_at: rel.published_at,
    apk_url: signed.signedUrl,
  }), {
    status: 200,
    headers: { "Content-Type": "application/json", "Cache-Control": "public, max-age=60", ...CORS },
  });
});

  push: { tags: ['v*.*.*'] }
permissions: { contents: read }

  release:
    runs-on: [self-hosted, linux, android]
    environment: production
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with: { distribution: temurin, java-version: '17' }
      - uses: subosito/flutter-action@v2
        with: { channel: stable, cache: true }

      - name: Restore keystore
        env: { KS_B64: '${{ secrets.ANDROID_KEYSTORE_B64 }}' }
        run: echo "$KS_B64" | base64 -d > android/app/release.keystore

      - name: Build
        env:
          SUPA_URL:  '${{ secrets.SUPABASE_URL }}'
          SUPA_ANON: '${{ secrets.SUPABASE_ANON_KEY }}'
        run: |
          flutter build apk --release \
            --build-name="${GITHUB_REF_NAME#v}" \
            --build-number="$(date +%s)" \
            --dart-define=SUPABASE_URL="$SUPA_URL" \
            --dart-define=SUPABASE_ANON_KEY="$SUPA_ANON"

      - name: Hash + verify
        run: |
          APK=build/app/outputs/flutter-apk/app-release.apk
          echo "SHA256=$(sha256sum $APK | cut -d' ' -f1)" >> $GITHUB_ENV
          echo "APK=$APK" >> $GITHUB_ENV
          $ANDROID_HOME/build-tools/*/apksigner verify --print-certs $APK

      - name: Publish to closed channel
        env:
          TG:   '${{ secrets.TELEGRAM_BOT_TOKEN }}'
          CHAT: '${{ secrets.TELEGRAM_CHANNEL_ID }}'
        run: |
          CAP=$(printf "🚀 *Версия %s*\n\nSHA-256: \`%s\`" "${GITHUB_REF_NAME#v}" "$SHA256")
          curl -sS -X POST "https://api.telegram.org/bot$TG/sendDocument" \
            -F chat_id="$CHAT" -F parse_mode=Markdown \
            -F caption="$CAP" -F document=@"$APK"
